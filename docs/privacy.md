# 隐私与安全

## 数据流

```text
你的消息
  → runtime/rin.py（本机）
  → 你的 LLM API（你配置的 base_url）
  → 回复
  → 本机 SQLite（data/rin.db）
```

- 笔记、状态、对话历史默认只存本机。
- 只有你实际发送给 LLM API 的内容会离开本机。
- 仓库不包含任何真实聊天记录、密钥或个人数据。

## 会存什么

| 表 | 内容 |
|---|---|
| `notes` | 笔记、日记、灵感、计划、备忘；含作者与可见性 |
| `interactions` | 每个对象的对话历史 |
| `state` | 每个对象的心情 / 精力 / 亲密度 / 上次说话时间 |
| `reminders` | 提醒内容与到期时间 |

## 可见性

- `self`：只有作者可见。运行时按 `author` + `can_read_private` 过滤。
- `shared`：共享视图可见；群聊也只展开 `shared`。
- 默认 `self`。只有显式共享才进共享视图。
- 不把一个人的私密内容转述给另一个人。

## 密钥

- 优先用环境变量 `RIN_API_KEY`。
- `config/rin.json` 里的 `runtime.api_key` 只适合本地临时测试；不要提交。
- `.gitignore` 已忽略 `config/rin.json`、`data/`、`.env`、`*.db`。
- 如果 key 泄露，立刻去服务商后台吊销并换新。

## 删除数据

参考运行时没有删除命令，直接删库即可：

```bash
rm data/rin.db          # macOS / Linux
Remove-Item data\rin.db # Windows PowerShell（如需可恢复，改用回收站）
```

注意 SQLite 可能还有 `rin.db-wal` / `rin.db-shm`，一起删。

## 群聊

群聊是公共场合：

- 只接公共话题和已经共享的安排。
- 不展开私聊历史、个人档案、情绪细节。
- 两个人都在场时点名说话，不只叫「你 / 他」。
- 不在群里执行私密查询（由宿主做权限拦截）。

## 安全边界

- 出现自伤 / 自杀表达：人设要求立刻停止玩笑，确认对方现在是否安全、身边有没有能马上找到的人，鼓励联系身边人或专业帮助。
- 不做心理诊断，不承诺保密，不替代危机干预。
- 不提供医疗、法律、投资建议。
- 被问是不是人：承认自己是 Rin，不假装人类。

## 已知风险

- **LLM  provider 的数据政策**：你发给 API 的内容受该服务商条款约束；敏感内容请用本地模型。
- **提示词注入**：如果聊天内容被拼进 system prompt，可能影响行为；运行时只把笔记作为「最近笔记」注入，仍建议在宿主层做长度和内容限制。
- **模型幻觉**：即使有工具回执，模型仍可能编造细节；重要事项请人工核对。
- **多用户隔离**：参考运行时按 `user_id` 分表存，但没有做鉴权；生产环境必须在网关层做身份校验。
